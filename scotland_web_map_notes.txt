USING OSRM

start docker daemon - sudo systemctl start docker
or just "dockerd" in another shell might be easier if running on windows with wsl

get osrm backend docker image - sudo docker pull osrm/osrm-backend

***
can skip this chunk if already have processed osrm data
https://github.com/Project-OSRM/osrm-backend/blob/master/README.md

Get .osm.pbf file (map data) from https://download.geofabrik.de/europe/united-kingdom/scotland.html

extract osm data - sudo docker run -t -v <location of .osm.pbf file>:/data osrm/osrm-backend osrm-extract -p /opt/car.lua /data/<scotland .osm.pbf file> || echo "osrm-extract failed"

some kind of processing step 1 (divides the routing graph into a hierarchical cell structure using recursive bisection) - sudo docker run -t -v <location of .osrm.* files>:/data osrm/osrm-backend osrm-partition /data/<scotland .osrm.* files name>.osrm || echo "osrm-partition failed"

some kind of processing step 2 (applies edge weights and processes traffic updates on the partitioned graph structure) - sudo docker run -t -v <location of .osrm.* files>:/data osrm/osrm-backend osrm-customize /data/<scotland .osrm.* files name>.osrm || echo "osrm-customize failed"
***

run osrm backend - sudo docker run -p 5000:5000 -v <location of .osrm.* files>:/data osrm/osrm-backend osrm-routed --algorithm mld /data/<scotland .osrm.* files name>.osrm

***
can get frontend image as well for testing if needed - docker pull osrm/osrm-frontend

launch - sudo docker run -p 9966:9966 osrm/osrm-frontend
can view in web browser at localhost:9966

this allows downloading of gpx data for any custom route with as many stops as who knows, gpx is just xml with coordinates so can use this to make a polyline & then just add popup labels & do css or whatever leaflet.js equivalent is
NOTE: osrm front end doesn't seem to want to let me actually add more than 2 points to a route, glitches out, try analysing (probably) json message from front end to back end
***

curl "localhost:5000/route/v1/driving/<lng>,<lat>;<lng2>,<lat2>;<lng3>,<lat3>;...?overview=full"
can do this^ for as many points as required, important to note the lat & lng are the opposite way round to in the js file
eg. -4.xxx will be first, then 55.xxx
this returns linestring which can be pasted into generate_route.js to generate generated_route.csv which is picked up by map.js

***
above is now automated, configure routes in route_nodes.csv then run the following:
sudo systemctl start docker
sudo docker run -p 5000:5000 -v /home/user/scotland_web_map/scotland_web_map_osrm_data:/data osrm/osrm-backend osrm-routed --algorithm mld /data/scotland-251209.osrm
node generate_route.js

remember to clean up any leftover docker containers & stop daemon
